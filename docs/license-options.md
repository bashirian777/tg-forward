# 许可证选择

当前仓库尚无 LICENSE，维护者选择后再添加完整许可证文本、年份 / 权利人和 `pyproject.toml` 的 SPDX 标识。依赖的许可证仍由各依赖项目提供。

| 选项 | 适用偏好 | 主要要求 |
| --- | --- | --- |
| MIT（建议） | 简洁，允许个人或商业使用、修改和再发布 | 保留版权及许可声明 |
| Apache-2.0 | 宽松授权，并希望明确专利授权与贡献条款 | 保留许可与必要通知，注明改动 |
| GPL-3.0-only | 希望分发的衍生软件继续采用 GPL | 分发时提供相应源码并维持许可 |

选择不影响目前的重构、测试或本地使用。维护者确认前不自行填写作者身份、加入任一许可证或宣称项目已经获得开源许可。
