Restore on the destination server:
1. Stop any existing instance:
   systemctl stop tg-forward.service 2>/dev/null || true
2. Verify the archive from its containing directory:
   sha256sum -c tg-forward-migration-no-venv-git-20261003-152051.tar.gz.sha256
3. Extract as root:
   tar --acls --xattrs --numeric-owner -xzpf tg-forward-migration-no-venv-git-20261003-152051.tar.gz -C /
4. Recreate the Python environment (Python 3.12 recommended):
   cd /root/tools/tg-forward
   python3.12 -m venv .venv
   .venv/bin/pip install -r requirements.txt
5. Reload and start:
   systemctl daemon-reload
   systemctl enable --now tg-forward.service
6. Verify:
   systemctl status tg-forward.service --no-pager
   journalctl -u tg-forward.service -n 100 --no-pager
